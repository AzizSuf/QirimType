# QırımType

**QırımType** — лёгкое фоновое Windows-приложение для удобного набора специфических букв крымскотатарского алфавита.

Пользователь продолжает использовать стандартную **английскую раскладку** клавиатуры, но при нажатии комбинации `Alt + буква` приложение бесшовно вставляет соответствующий крымскотатарский символ через Windows API (SendInput Unicode).

Приложение работает в области уведомлений (System Tray), не требует прав администратора, не изменяет системные раскладки Windows и не нагружает процессор.

---

## Поддерживаемые символы и горячие клавиши

| Shortcut | Character | Название символа | Код Unicode |
| :------- | :-------: | :--------------- | :---------- |
| **Alt + G** | **ğ** | Latin Small Letter G with Breve | `U+011F` |
| **Alt + I** | **ı** | Latin Small Letter Dotless I | `U+0131` |
| **Alt + N** | **ñ** | Latin Small Letter N with Tilde | `U+00F1` |
| **Alt + O** | **ö** | Latin Small Letter O with Diaeresis | `U+00F6` |
| **Alt + U** | **ü** | Latin Small Letter U with Diaeresis | `U+00FC` |
| **Alt + C** | **ç** | Latin Small Letter C with Cedilla | `U+00E7` |
| **Alt + S** | **ş** | Latin Small Letter S with Cedilla | `U+015F` |

> [!NOTE]
> * Поддерживаются **только строчные буквы**.
> * **Работа только в английской раскладке**: Замена клавиш происходит исключительно тогда, когда в активном окне включена английская раскладка клавиатуры (ENG). В русской, украинской и любых других раскладках приложение не вмешивается и не перехватывает символы.
> * Сочетания с `Shift` (например, `Alt+Shift`) намеренно не перехватываются и свободно переключают язык.
> * Комбинации с `Ctrl` (включая `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+Z`, `Ctrl+A`) и клавишей `Win` никогда не блокируются.

## Особенности и преимущества

* **Нативный Unicode-ввод**: Ввод символов осуществляется через Windows API `SendInput` с флагом `KEYEVENTF_UNICODE`, без использования буфера обмена (Clipboard) и без искажения содержимого буфера пользователя.
* **Работает везде**: Поддерживается в блокноте (Notepad), Microsoft Word, браузерах (Chrome, Firefox, Edge), Telegram, Discord, VS Code, терминалах и любых других текстовых редакторах.
* **Умное подавление системного Alt**: Исходные нажатия клавиш подавляются, а при отпускании Alt фоновое окно не переключает фокус на строку меню (Menu Bar / Ribbon).
* **Минимальное потребление ресурсов**: Никакого CPU-поллинга. Обработка клавиш происходит мгновенно по событиям низкоуровневого хука Windows (`WH_KEYBOARD_LL`). В режиме ожидания потребление CPU — 0.0%.
* **Системный трей**: Компактное размещение возле часов. Доступ к включению/выключению, окну настроек, автозапуску и выходу в один клик.
* **Кастомизация клавиш**: Любое сочетание можно переназначить через окно настроек.
* **Автозапуск с Windows**: Включение автозагрузки для текущего пользователя через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` без необходимости прав администратора.

## Принцип работы Keyboard Hook

1. **Установка хука**: При запуске приложение вызывает `SetWindowsHookEx(WH_KEYBOARD_LL, ...)` с глобальной областью видимости.
2. **Фильтрация событий**:
   * При получении сообщения `WM_KEYDOWN` или `WM_SYSKEYDOWN` проверяется состояние модификаторов через `GetAsyncKeyState`:
     * Клавиша `Alt` должна быть зажата (`LLKHF_ALTDOWN` или `VK_MENU`).
     * Клавиши `Ctrl`, `Shift`, `Win` **не** должны быть зажаты.
   * Если зажата незарегистрированная клавиша (например, `Alt+Tab`, `Alt+F4`), хук немедленно передаёт событие дальше по цепочке через `CallNextHookEx`.
3. **Подавление и подмена**:
   * Если зажата одна из зарегистрированных букв (например, `G`):
     * Код клавиши регистрируется во внутреннем списке подавления.
     * Запоминается признак использования Alt для символа.
     * Вызывается `UnicodeInput.SendUnicodeString("ğ")`:
       1. Логически отпускается `Alt` (`KEYEVENTF_KEYUP` с маркировкой `QRMT_EXTRA_INFO`).
       2. Вставляется Unicode-символ (`KEYEVENTF_UNICODE` нажатие и отпускание).
     * Процедура хука возвращает `(IntPtr)1`, блокируя исходную комбинацию от попадания в активное приложение.
4. **Защита от рекурсии**:
   Все события `SendInput`, создаваемые приложением, маркируются уникальным `dwExtraInfo = 0x51524D54` (`QRMT`). Процедура хука проверяет этот маркер и игнорирует собственные синтезированные нажатия.
5. **Защита от активации меню Alt и предотвращение залипания клавиш**:
   Перед логическим отпусканием `Alt` при вводе символа в систему отправляется фиктивное нейтральное событие маскировки (`VK_NONAME`), которое сообщает Windows о том, что `Alt` был нажат в составе комбинации, и сбрасывает флаг вызова меню окна. Физические события отпускания модификаторов (`WM_KEYUP` для Alt, Shift, Ctrl, Win) всегда беспрепятственно передаются в систему. Это исключает рассинхронизацию очередей ввода, предотвращает залипание клавиш и обеспечивает плавную смену раскладки (`Alt+Shift`, `Win+Space`).
6. **Корректная выгрузка**:
   При выходе из приложения или закрытии контекста трея вызывается `UnhookWindowsHookEx`, гарантируя полное и чистое освобождение системных ресурсов.

## Сборка и запуск

### Требования

* Операционная система: Windows 10 или Windows 11 (x64)
* Для сборки из исходников: [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) (или новее)

### Сборка проекта

Выполните в корневой папке проекта:

```bash
dotnet build
```

### Запуск тестов

Для запуска набора модульных и интеграционных тестов:

```bash
dotnet test Tests\QirimType.Tests.csproj
```

### Публикация автономного (Self-Contained) релиза

Для создания единого исполняемого файла, работающего на любом компьютере с Windows 10/11 x64 без необходимости установки .NET Runtime:

```bash
dotnet publish -c Release -r win-x64 --self-contained true
```

Готовый файл `QirimType.exe` будет находиться в каталоге:
`bin\Release\net8.0-windows\win-x64\publish\QirimType.exe`

## Настройка приложения

1. **Контекстное меню в системном трее**:
   * Кликните правой кнопкой мыши по иконке **Q** в области уведомлений.
   * **Включено (Enabled ✓)**: клик переключает состояние приложения (активно / приостановлено).
   * **Настройки (Settings...)**: открывает окно конфигурации клавиш.
   * **Автозапуск (Start with Windows)**: переключает автозагрузку при входе в систему.
   * **О программе (About...)**: справочная информация и версия.
   * **Выход (Exit)**: завершение работы и корректное снятие хука.
2. **Переназначение клавиш**:
   * Откройте окно **Настройки**.
   * Нажмите кнопку **«Изменить»** напротив нужного символа.
   * Нажмите новую клавишу на клавиатуре (например, букву `K`).
   * Нажмите кнопку **«Сохранить»**.
3. **Сброс настроек**:
   * В окне **Настройки** нажмите **«По умолчанию»** (Restore defaults), чтобы вернуть стандартные комбинации `Alt + G`, `Alt + I`, `Alt + N`, `Alt + O`, `Alt + U`, `Alt + C`, `Alt + S`.

Файл настроек сохраняется в каталоге пользователя:
`%APPDATA%\QirimType\settings.json`
